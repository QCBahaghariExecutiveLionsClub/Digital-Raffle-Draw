🎲 How Every Winner Is Chosen

  1. Only paid, active tickets are eligible. The list comes straight from the Registrations sheet each time it's loaded.
  2. Past winners are removed automatically. Once a ticket wins, it can never be picked again in the same event — no one gets a second chance.
  3. The computer picks, not a person. The winning ticket is chosen using the device's built‑in secure random number generator (crypto.getRandomValues) — the same technology used to generate secure passwords. No one, including the operator, can influence or predict the result.
  4. Every remaining ticket has an equal chance. If 187 tickets are eligible, each one has exactly a 1‑in‑187 chance — shown on screen before every draw.
  5. Everything is logged. Round, prize, eligible count, excluded count, and the winning ticket are all saved and can be downloaded as an audit log after the event.
